Script Finder <script>

Paste a page link and its source, and get every script the page loads: external files, inline code, modules, preloads, data blocks and inline event handlers.

Browsers don't let a page read another site directly, so copy the page's source in two quick steps: paste the view-source: address shown above into a new tab, then press Ctrl+A and Ctrl+C (⌘A, ⌘C on Mac).
