Bot Invite Builder

Make the official link that adds a bot to a server, from its client ID. You approve it on Discord, so you need Manage Server on that server.

1. The bot and the server

Developer Portal → your app → General Information → Application ID. Example filled in: Codey.
An invite link only lets people join. It can't add a bot, so this page just checks the link is valid and shows you which one you are working with. You pick the server on Discord's own screen.
Discord Settings → Advanced → Developer Mode on, then right-click your server → Copy Server ID.

2. Permissions

Preset
Administrator gives the bot full control and ignores every channel and role limit. If its token leaks, someone else controls your server. Prefer Chat bot unless you need more.

3. Your invite link

Enter a valid client ID to build the link.
Open on Discord
  1. Open the link and sign in to Discord.
  2. Choose your server in the dropdown, then press Continue.
  3. Check the permissions and press Authorize.

This page never asks for your password or a bot token. Do not paste a token anywhere here.
